# VALERIAN Android build (experimental V20 branch)

This branch is an isolated packaging workspace. The published GitHub Pages site on `main` is not changed.

## Requirements
- Node.js 22 or newer
- Android Studio with Android SDK installed
- JDK version supported by the installed Android Gradle Plugin

## First Android project setup
```bash
npm install
npm run android:add
```

## After changing the web app
```bash
npm run android:sync
npm run android:open
```

Then use Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s).

## Important
- This creates a native Android wrapper around the existing VALERIAN web interface; it does not yet redesign or migrate the database.
- Keep the existing website and its browser data intact during testing.
- Do not use this experimental build for live business records until offline behavior, printing, image export, authentication, sync, and backup/restore have been tested on-device.
- The Android project folder is generated by Capacitor locally and is not committed by this initial scaffold.
